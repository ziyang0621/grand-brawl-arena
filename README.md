# Grand Brawl Arena

## 海贼大乱斗（v20，资源 v38）

向 PS2《One Piece Grand Battle》靠拢的网页 3D 乱斗：开场先进入**角色 / 场地选择**，对战为**三局两胜、每局 99 秒**，有 ROUND / FIGHT! / K.O. 演出、必杀切入画面和 K.O. 慢镜头。所有角色与场地均为原创，不使用任何 One Piece 版权角色或素材。

### 连段与移动（v19）

- **双击方向键奔跑**：速度约 1.6 倍，奔跑中的移动技突进更远；松开方向、出招或防御即停。
- **浮空追击**：W＋U 上挑把对手打上天 → 空格跳起 → 连按 J 空中连击；第三下空中攻击把对手砸向地面并反弹（砸地后无法受身）。浮空连段有伤害递减，一整套约 35% 体力，最多 5 段。
- 画面左右会显示连击数「N HITS!」；电脑也会上挑追击、远距离奔跑接近。
- 开战前有 VS 对决画面和镜头环绕；落地、奔跑扬尘，被击飞有速度线，重击和 K.O. 有轻微震屏（系统开启「减少动态效果」时关闭）；胜利画面显示角色台词。

### 画面

透视三分之四镜头随双方距离缩放；三阶硬边卡通着色＋墨线描边；天空穹顶、飘云、风车、帆船等动态布景。HUD 采用格斗游戏风格：头像、斜切体力条（受伤红色延迟条、低血闪烁）、回合胜利灯、底部三格必杀槽（显示当前可用等级）。命中时出现漫画星形火花与伤害数字。

### 操作

WASD / 方向键在场地中移动，空格二段跳，连按 J 衔接三段连击。移动 + J 为角色专属移动技（见上表）。U 重击，W + U 上挑，I 抓人或举起容器。抓中对手后按 J 前投、U 高投；被抓方连按 J/U/I 可挣脱。举起物品后仍是 J 前投、U 高投。K 使用道具，Shift 闪避。
L 使用一级必杀，Shift + L 使用二级必杀，R + L 使用三级奥义。
必杀有 0.4 / 0.55 / 0.7 秒蓄力，地面范围圈会逐渐填满，血条下显示倒计时；蓄力期间停步、无施法无敌，可被攻击打断且不返还能量。可跑出范围、适时闪避，或跳过蓝方震盾。AI 也会使用和应对必杀。
Q 切换近身朝向辅助（默认开启）。红帆旋风斩伤害高、可对空；蓝潮震盾范围大、击退强，但高度超过 1.2 的对手可以避开。受击飞出后可撞栏反弹、撞碎箱子。
近战格挡只覆盖面向前方：普通正面命中减伤约 75%，侧后方命中正常扣血且不能完美反击。松开 R、转身后再举盾；重击仍可正面破防。范围技能/道具维持各自原有判定。
被击飞下降时，在落地前 0.16 秒内按方向＋空格可翻滚受身，提前结束倒地并获得短暂保护；过早按无效。受身期间不能攻击，中毒、感染或冻伤时不能发动。
抓投现在带短暂抬起、挣扎、出手和翻滚动作；举人者受击会松手，失去一条命也会清理抓取关系。举起期间不能跳跃、挡键或使用道具，仍能移动并按 J/U 投掷。
注意：3D 版的 W 是向场地后方移动，跳跃改为空格。

- 选择画面：← → 切换 1P 角色，↑ ↓ 切换场地，Enter 开始；对局中点右上「角色选择」可返回。练习模式在首次移动或攻击后才开始；切换窗口自动松开按键。
- 在选择画面点击「跳台练习」，再按空格，可以验证中央甲板落地。
- 在选择画面点击「对手：战斗 AI」切到静止练习，角色置于试刀距离；按 J 可以看到对手扣血。
- 战斗 AI 会争抢道具、受伤找肉、开箱和装备强化刀；近战交替轻击/重击/抓投，遇到格挡会尝试重击。
- 三座绿色甲板为可从下方跳穿、从上方落稳的平台，楼梯可以上下攀爬。
- 木桶、木箱和宝箱拥有不同掉落池，也可以举起后向前投掷或高抛。
- 道具由范围内最近且能拾取的存活角色获得；满血不会消耗肉块，死亡/等待重生不能拿道具，肉块不能抵消已经发生的死亡。
- 港口会定时炮击并出现巨浪预警；跳上绿色甲板可以避开低处巨浪。
- 3D 联机：两个人打开同一个 3D 页面，房主在选择画面点击「创建房间」，朋友先选好自己的角色，再输入四位房间码点击「加入房间」；房主决定场地和自己的角色。房主负责权威战斗模拟，朋友端发送操作并接收状态同步。
- 双人镜头以两名玩家中点取景，按两人距离平滑拉远；不再使用随机震屏，减少眩晕。
- 抓住对手后可以慢速移动，被抓双方不会再被身体碰撞推开；持有人可主动前投/高投。
- 当前支持 2 人 3D 联机房间。
- 联机结算后双方点击再战才开始下一局；房主切到后台时暂停。旧回合操作被过滤，朋友端输入超过 500ms 未更新会归零。

使用 Node.js 20+：

```sh
npm start
npm test
```

访问 `http://127.0.0.1:4173/three-preview.html?v=38`（端口可用 `PORT=4180 npm start` 修改）。Three.js 0.180.0 位于 `vendor/`，无需安装 npm 依赖。
游戏服务器只公开游戏文件，禁用缓存；Cloudflare Quick Tunnel 地址为临时地址，不能视为固定线上链接。

`arena-core.js` 为独立战斗模拟（含回合流程），`arena-roster.js` 为角色数据与各场地的高台、地形区、机关定义（模拟与画面共用），`arena-models.js` 构建角色模型与头像，`arena-stage.js` 构建三个场地，`arena-gfx.js` 提供卡通着色与描边工具，`arena.js` 负责渲染、HUD、选人与输入，`arena-clouds.js` 负责危险雾区几何和渐隐，`arena-session.js` 负责输入有效期与再战规则，`arena.css` 为界面样式。
回归测试覆盖平台跑跳与落地、走下平台、二段跳限制、刀击距离/高度、炸弹/技能伤害、冷却、回血与胜负。

## 玩法

- 建房：点「创建房间」，把 4 位房间码发给朋友
- 加入：朋友输入房间码进入（2 人，P2P 直连）
- 规则：可以选择普通对战或三命模式，也有单人 AI 和静止练习

## 技术

3D 页面通过 PeerJS（公共免费信令云 0.peerjs.com）进行 P2P 联机，
房主为权威端做 120Hz 固定步长模拟，20Hz 广播状态。需要通过 HTTP 服务打开页面，也可部署到静态托管服务。
