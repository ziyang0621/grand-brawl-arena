# Grand Brawl Arena

## 3D 港湾乱斗（v11）

网页现在只保留 `three-preview.html` 这一套 3D 竞技场：港口甲板、持刀角色、战斗 AI、血条和胜负结算，也支持 PeerJS 房间联机。打开 `index.html` 会进入 3D 版本。
WASD / 方向键在场地中移动，空格二段跳，J 连斩，移动 + J 冲刺斩，U 重击，W + U 上挑，I 抓人或举起容器，K 使用道具，Shift 闪避。
L 使用一级必杀，Shift + L 使用二级必杀，R + L 使用三级奥义。
注意：3D 版的 W 是向场地后方移动，跳跃改为空格。

- 首次移动或攻击后才开战；切换窗口自动松开按键。
- 点击「跳台练习」，再按空格，可以验证中央甲板落地。
- 点击「对手：战斗 AI」切到静止练习，角色置于试刀距离；按 J 可以看到对手扣血。
- 三座绿色甲板为可从下方跳穿、从上方落稳的平台，楼梯可以上下攀爬。
- 木桶、木箱和宝箱拥有不同掉落池，也可以举起后向前投掷或高抛。
- 港口会定时炮击并出现巨浪预警；跳上绿色甲板可以避开低处巨浪。
- 3D 联机：两个人打开同一个 3D 页面，房主点击「创建 3D 房间」，朋友输入四位房间码后点击「加入 3D 房间」。房主负责权威战斗模拟，朋友端发送操作并接收状态同步。
- 当前支持 2 人 3D 联机房间。

使用 Node.js 20+：

```sh
npm start
npm test
```

访问 `http://127.0.0.1:4173/three-preview.html`。Three.js 0.180.0 位于 `vendor/`，无需安装 npm 依赖。
游戏服务器只公开游戏文件，禁用缓存；临时 HTTPS 隧道可继续指向 4173 端口。

`arena-core.js` 为独立战斗模拟，`arena.js` 负责 3D 渲染与输入，`arena.css` 为界面样式。
回归测试覆盖平台跑跳与落地、走下平台、二段跳限制、刀击距离/高度、炸弹/技能伤害、冷却、回血与胜负。

## 玩法

- 建房：点「创建房间」，把 4 位房间码发给朋友
- 加入：朋友输入房间码进入（2 人，P2P 直连）
- 规则：可以选择普通对战或三命模式，也有单人 AI 和静止练习

## 技术

3D 页面通过 PeerJS（公共免费信令云 0.peerjs.com）进行 P2P 联机，
房主为权威端做 60Hz 模拟。直接用浏览器打开即可玩，也可部署到 GitHub Pages。
